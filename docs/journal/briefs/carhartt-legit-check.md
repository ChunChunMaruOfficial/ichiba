## Правило фактов для легит-чеков (обязательно)

В этом брифе **не задаются конкретные признаки подделок** («у оригинала на бирке шрифт такой-то», «молния только YKK» и т. п.) — такие утверждения часто устаревают и расходятся по годам выпуска и фабрикам. Автор берёт конкретику только из двух источников:
1. Проверяемые внешние источники: официальный сайт бренда (описание продукта, состав, артикулы), официальные ответы бренда о подделках, профильные сообщества и сервисы аутентификации — каждое утверждение с названием источника и датой проверки; спорные признаки — с оговоркой «по данным <источник>, для вещей <годы>».
2. Собственные фото лотов с платформы: оригинальные вещи Carhartt, которые продавцы ichiba согласились сфотографировать по нужным ракурсам (бирки, швы, фурнитура). Подписи к фото — только то, что видно на фото, без «а у подделки будет иначе», если подделки для сравнения в руках не было.

Если по какому-то пункту проверяемого источника нет — пункт остаётся в форме «что проверять» (какой элемент и как сфотографировать), без описания «как должно быть».

## Тезисы для блока «Коротко» (заготовки, не готовый текст)

- Carhartt WIP и Carhartt USA — две линейки; проверять надо ту, что заявлена в объявлении.
- Пять зон проверки по фото: бирки, швы, фурнитура, лейбл, коды.
- Какие фото попросить у продавца одним сообщением.
- Как сверить артикул с официальным каталогом бренда.
- Когда цена — сама по себе сигнал (вилка цен б/у по данным ichiba).

## Цифры и источники

Минимум две цифры с источником, лучше четыре:
- Число лотов Carhartt / Carhartt WIP в каталоге, медианная цена б/у по категориям (куртка, худи, карго), доля «Новое» среди них — `server/scripts/journal-stats.ts` (скрипт планируется; пока запросить выгрузку у владельца).
- Цены новых вещей — официальный сайт Carhartt WIP / Carhartt, с датой проверки.
- Данные о масштабе рынка подделок одежды — только официальные отчёты (например, таможенные или отраслевые с указанием организации), с пометкой «проверить актуальность»; если надёжного источника нет — цифру не приводить.

## Чего избегать

- Признаков подделок «из головы» или с анонимных форумов без источника.
- Фото чужих лотов/гайдов: только свои снимки с согласия продавцов или официальные изображения с указанием источника.
- Утверждений «100 % оригинал, если…»: везде оговорка, что проверка по фото снижает риск, но не исключает его.
- Называния конкретных продавцов как источников подделок.
- Повтора «carhartt оригинал» в каждом абзаце (плотность ≤ 2–3 %).
