## Интент

Информационный с коммерческим хвостом: человек хочет узнать, какие вообще есть белорусские марки (для себя, в подарок, из принципа «покупать своё»), и сравнить их по стилю и цене. Это справочник, к которому возвращаются. У каждой марки должен быть ответ на четыре вопроса: что это, для кого, сколько стоит, где взять.

Угол, которого нет у конкурентов (по карте выдачи в плане — каталоги фабрик и «Топ-10»): у каждой марки указана не только цена нового, но и цена б/у на ichiba, то есть «попробовать бренд можно дешевле».

## Целевые страницы каталога

- `/brands` — главная ссылка хаба («все бренды в каталоге»).
- `/brands/<brand-slug>` для каждой марки, у которой есть лоты (страница появляется, когда в каталоге есть лоты бренда): `/brands/mirarwear`, `/brands/i-love-redhead`, `/brands/vandal-era`, `/brands/znwr`, `/brands/mark-formelle`, `/brands/milavitsa`, `/brands/conte`. Перед публикацией открыть каждую ссылку; бренды без лотов — без ссылки, с пометкой «на ichiba пока нет».
- `/sell` — один бэнд `cta-sell` в конце: «вещи белорусских брендов, которые вы не носите».
- `/c/knitwear`, `/c/tshirts` — категории, где белорусские марки заметнее всего (проверить по выгрузке, не по ощущениям).

## Как собрать список марок (список НЕ придумывать)

Источники по убыванию приоритета:
1. Бренды, уже представленные на платформе: магазины-бренды mirarwear (MIRARWEAR), I LOVE REDHEAD, vandal.era, плюс марки, которые встречаются в лотах других продавцов. Выгрузка «белорусские бренды по числу лотов и медианной цене» — `server/scripts/journal-stats.ts` (скрипт планируется; пока запросить выгрузку у владельца).
2. Запрос владельцу: список марок, с которыми идёт или планируется работа (база белорусских брендов для аутрича ведётся вне репозитория; в статью попадают только названия, никаких контактов).
3. Проверка каждой марки по её сайту и соцсетям: бренд действует (есть публикации за последние несколько месяцев), есть где купить, виден ценовой диапазон. Дата проверки фиксируется в рабочей таблице автора.
4. Открытые источники для расширения (публикации BY-медиа о локальных марках, каталоги производителей) — только как подсказка; каждая марка всё равно проходит пункт 3.

Критерии включения: белорусское происхождение (основатели или производство в Беларуси), действующая марка, одежда (обувь и сумки — отдельная статья `belarusian-shoe-and-bag-brands`), вещи можно купить сейчас. Фабрики с советской историей включаются, если у них есть потребительский бренд, а не только производство под заказ.

Группы (ориентир, по 3–7 марок): стритвир и молодые марки; дизайнерская женская одежда; базовый гардероб и трикотаж; бельё и чулочно-носочные изделия; верхняя одежда; детская одежда (по желанию).

## Тезисы для блока «Коротко» (заготовки, не готовый текст)

- Сколько марок в списке и на какие группы они разбиты.
- Какая группа заметнее всего на ichiba по числу лотов (данные `journal-stats`).
- Насколько б/у вещи белорусских брендов дешевле новых (данные ichiba + цены с сайтов).
- Три канала, где купить: магазины брендов, маркеты и шоурумы, открытые гардеробы.
- Когда список обновляется в следующий раз (дата ревизии).

## Цифры и источники

Минимум две цифры с источником, лучше четыре:
- Число лотов и медианная цена по каждому белорусскому бренду на ichiba — `server/scripts/journal-stats.ts` (скрипт планируется; пока выгрузка у владельца).
- Отношение медианной цены б/у к цене нового по 3–5 брендам: б/у — из выгрузки, новое — с сайта бренда, с датой проверки.
- Год основания и город каждой марки — сайт или соцсети бренда, с датой проверки.
- Одна «большая» цифра для вводной (объём лёгкой промышленности или экспорт текстиля) — Белстат; проверить актуальность. Необязательно.
- Все цифры в тексте — через `<Stat/>` с источником.

## Кого цитировать

- Основатель или представитель марки с платформы (роль: основатель стритвир-бренда) — почему шьют в Беларуси и для кого.
- Владелец мультибрендового шоурума локальных марок (роль) — что спрашивают покупатели.
- Представитель ichiba (роль: основатель) — одна фраза про долю белорусских брендов в каталоге, не рекламная.

Каждая цитата — с именем и ролью, с согласия человека. Репозиторий публичный: контакты в текст не попадают.

## Чего избегать

- Список марок по памяти или из чужих подборок без проверки по сайту бренда.
- Копирование описаний «о бренде» с сайтов марок.
- Оценочные «лучший белорусский бренд», рейтинги без критерия.
- Марки, которые закрылись или давно не публикуются.
- Выдуманные годы основания, города, цены.
- Ссылки `/brands/<slug>` на бренды, у которых нет лотов.
- Повтор «белорусские бренды одежды» в каждом абзаце (плотность ≤ 2–3 %).
