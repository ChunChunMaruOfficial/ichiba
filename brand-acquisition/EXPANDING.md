# Как расширять базу брендов

## Цикл (раз в 1–2 недели, ~1 час)

1. Добавить новые страницы-подборки в `data/seeds/source_pages.txt` (по одной на строку, `# комментарий`).
2. `python brand-acquisition/scripts/pipeline.py discover` → в `data/leads_discovered.csv` появятся ссылки на
   Instagram/Telegram/сайты, которых ещё нет в базе.
3. Разобрать кандидатов: открыть профиль, решить «бренд со своим продуктом / нет». Подходящих дописать в новый
   seed-файл, например `data/seeds/2026-11-batch.json` (формат — `data/seeds/SCHEMA.md`), в `leads_discovered.csv`
   поставить `status` = `brand` или `not_brand` (повторно эти ссылки не появятся).
4. `python brand-acquisition/scripts/pipeline.py all` — проверка, оценка, экспорт; CRM пополнится новыми A/B.

## Где искать (по опыту первой выборки — см. «Полезные источники» в REPORT.md)

- **Подборки СМИ** «белорусские бренды одежды» за последние 2 года (CityDog, Onliner, KYKY, Relax, bel.ru, 34mag,
  Holiday). Ищите обновлённые ежегодные списки.
- **Концепт-сторы и шоурумы Минска**: на их сайтах и в Instagram — списки представленных локальных марок. Один
  такой список даёт 10–30 кандидатов.
- **Маркеты дизайнеров и ярмарки** (участники в анонсах).
- **Fashion-недели и конкурсы** (участники Belarus Fashion Week / Fashion Days, студенческие конкурсы дизайнеров).
- **Telegram**: каталоги каналов (tgstat.ru/by, telemetr) по словам «бренд одежды», «пошив», «дроп», «Минск»;
  у брендов в описании канала часто есть контакт для заказов.
- **Маркетплейсы**: у белорусских брендов на Wildberries/Ozon в карточке продавца указаны название и УНП — по
  названию находятся сайт и соцсети.
- **Рекомендации подключённых брендов**: спросить после подключения «кого из коллег вы бы позвали» — самый тёплый канал.
- **Instagram** (вручную): хэштеги и упоминания в профилях брендов, «похожие аккаунты» у подходящего бренда.

## Поисковые запросы, которые стоит повторять

```
белорусский бренд одежды {streetwear | худи | лён | трикотаж | верхняя одежда | платья | минимализм}
минский бренд одежды собственное производство
бренд одежды {Гродно | Брест | Гомель | Витебск | Могилёв} пошив
беларускі брэнд адзення
belarusian clothing brand {streetwear | designer | linen}
локальные бренды Минск концепт-стор
дроп худи Минск telegram
```

## Чего не делать
- Не автоматизировать сбор из Instagram/TikTok (запрещено их правилами, приводит к блокировкам).
- Не собирать личные контакты сотрудников, если есть официальный контакт бренда.
- Не добавлять бренды «на всякий случай»: без подтверждения своего продукта — только лист «На доп. проверку».

## Дальнейшая автоматизация (по мере роста)
- Подключить официальный поисковый API (например, Yandex Search API или Brave Search API) к `discover`, чтобы
  запросы выше выполнялись по расписанию — потребует ключа; бесплатные тарифы есть, но с лимитами.
- Хранить CRM в той же базе, что и ichiba (таблица заявок брендов уже есть: `BrandApplication`) — тогда статус
  «заявка подана/подключён» будет обновляться сам.
- Отчёт для подключённых брендов «ваши вещи за месяц» — из уже существующей статистики `/sales/stats`.
