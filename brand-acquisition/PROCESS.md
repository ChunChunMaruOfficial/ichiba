# Процесс привлечения брендов: от поиска до первых продаж

## Воронка

| # | Этап | Что делаем | Автоматизация | Нужен основатель |
|---|---|---|---|---|
| 1 | Поиск | Подборки СМИ, концепт-сторы, шоурумы, маркеты дизайнеров, Telegram-каталоги, поиск по запросам (см. `EXPANDING.md`) | `pipeline.py discover` вытаскивает новых кандидатов со страниц-подборок в `data/leads_discovered.csv` | Нет (агент/ассистент) |
| 2 | Проверка | Свой ли продукт, жив ли бренд, официальные контакты | `pipeline.py verify`: сайт отвечает, email/телефон/соцсети на официальных страницах, Telegram-канал (подписчики, последний пост) | Instagram/TikTok — **только вручную** (запрет автосбора) — 1–2 мин на бренд |
| 3 | Приоритет | Балл 0–100, группы A/B/C | `pipeline.py score` | Просмотреть топ, поправить явные ошибки через `data/overrides.json` |
| 4 | Канал связи | email → Telegram → Instagram Direct → форма | Колонка «Канал первого контакта» | — |
| 5 | Персонализация | Одна конкретная деталь о бренде | Заготовки «Почему ichiba» и «Аргумент» в таблице | **Да**: открыть профиль, выбрать деталь (3–5 мин) |
| 6 | Первое сообщение | Шаблоны А/Б/В из `outreach/messages.md` | Можно подготовить черновики пачкой | **Да**: отправлять вручную, с личного/брендового аккаунта. Массовую автоотправку в Instagram/Telegram не делать — бан и спам |
| 7 | Повторный контакт | +4–5 дней, затем +7–10 дней, максимум 3 касания | CRM: «Дата следующего касания», фильтр по сегодняшней дате | Отправка — вручную |
| 8 | Возражения | Таблица ответов в `messages.md`, раздел Ж | — | **Да** |
| 9 | Демонстрация | 2–3 скриншота или созвон 10–15 минут: каталог брендов, профиль бренда-примера, карточка вещи, статистика | — | **Да** |
| 10 | Подключение | Регистрация → заявка «Статус бренда» в Настройках → одобрение в `/admin/brands` → перенос каталога (TG/сайт/фото) или самостоятельная выкладка | Перенос: `server/src/tg`, `server/src/shops`, `hand-listings.ts` — настройка источника разработчиком | **Да**: одобрение заявки, решение по переносу |
| 11 | Результаты | Через 2 и 6 недель: вещей на площадке, просмотры, ♡, запросы, продажи (статистика `/sales/stats` у бренда, админка у основателя) | Метрики уже считаются площадкой | Созвон/сообщение бренду с цифрами его вещей — повод для отзыва и рекомендаций |

### Минимальный онбординг бренда (чек-лист)
1. Бренд регистрируется (Google / телефон / почта / Telegram) и выбирает ник.
2. Настройки → «Статус бренда» → название, форма (ИП/ООО/самозанятый/физлицо; для ИП и ООО — УНП), контакт, ссылки, 2 предложения о бренде.
3. Основатель одобряет заявку в `/admin/brands` → на профиле и вещах появляется печать «Бренд», новые вещи идут в каталог брендов.
4. Ассортимент: (а) перенос из Telegram-канала, (б) синхронизация с сайтом, (в) выкладка по фото командой, (г) бренд выкладывает сам.
5. Бренд подключает уведомления в Telegram (Настройки → Telegram) и указывает способы передачи: лично / доставка.
6. Через неделю — сообщение с первыми цифрами по вещам.

## CRM

Файл `data/crm.csv` (открывается в Excel; лист «CRM» в `output/ichiba_brands.xlsx` — копия на момент экспорта
с выпадающим списком статусов). Скрипт **только добавляет** новые бренды групп A/B и никогда не перезаписывает
заполненные строки — CRM можно вести прямо в CSV.

| Поле | Значение |
|---|---|
| ID | ключ бренда из базы (связь с `brands.json`) |
| Бренд, Группа | из базы |
| Канал связи, Контакт | куда писать |
| Ответственный | кто ведёт |
| Статус | не начато → написали → follow-up 1 → follow-up 2 → ответили → созвон/демо → заявка подана → подключён → первые товары; отдельно: отказ, не сейчас (вернуться), нет контакта |
| Дата первого сообщения, Дата следующего касания, Касание № | для очереди касаний |
| Ответ, Возражения | кратко, своими словами |
| Следующий шаг | одно действие с датой |
| Дата подключения, Товаров на ichiba | для итоговых метрик |
| Заметки | всё остальное |

Ежедневная рутина (15–30 мин): отфильтровать «Дата следующего касания ≤ сегодня» → отправить → обновить статус и дату.

## KPI первых недель

Ориентиры, не гарантии. Для холодных сообщений небольшим брендам от реального основателя ответ получают обычно
меньше половины адресатов; подключаются единицы. Фактические цифры записывать в CRM и пересматривать план через 2 недели.

| Неделя | Действие | Целевой ориентир |
|---|---|---|
| 1 | Написать группе A (до 20 брендов), персонально | 20 первых сообщений; 5–8 ответов — хороший результат |
| 2 | Follow-up по группе A, первые сообщения группе B (20–30) | 3–5 созвонов/демо; 2–3 заявки «Статус бренда» |
| 3–4 | Перенос каталогов подключившихся, касания 3, новые бренды из `discover` | 5–10 подключённых брендов, у каждого ≥10 вещей на площадке |
| 6 | Сводка по подключённым: просмотры/♡/запросы по вещам | Повод для рассказа следующим брендам («у X за месяц N просмотров» — только реальные цифры и с согласия бренда) |

Ключевые метрики: доля ответов (ответили / написали), конверсия в заявку, время от «да» до первых 10 вещей на площадке,
доля брендов с ≥1 запросом покупателя за первый месяц.

## Что важно не делать
- Массовую автоматическую рассылку в Instagram/Telegram — бан аккаунта и репутация «спамера» в маленьком сообществе.
- Писать одному бренду через несколько каналов одновременно.
- Обещать продажи, трафик, продвижение, «без комиссии» и эксклюзивы, которые не решены.
- Публиковать вещи бренда до его явного согласия (перенос каталога — только после «да»).
